# ระบบเว็บสต๊อกสินค้าและจัดการร้าน พรชัยแบตเตอรี่ บางพลี 🔋

ระบบบริหารจัดการร้านแบตเตอรี่แบบครบวงจร พัฒนาด้วย **PHP + MySQL (MariaDB)** และออกแบบส่วนติดต่อผู้ใช้ด้วย **Bootstrap 5, Bootstrap Icons และ Google Fonts (Noto Sans Thai, Sarabun)** รองรับการทำงานทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน

---

## 📋 ฟังก์ชันและระบบทั้งหมดตามความต้องการ

### 1. ระบบสมาชิก (Member System)
- **สมัครสมาชิก (`register.php`):** ฟอร์มกรอกชื่อ-นามสกุล, เบอร์โทร, อีเมล, ที่อยู่, ชื่อผู้ใช้, รหัสผ่าน
- **เพิ่มรถได้มากกว่า 1 คัน:** ในขั้นตอนสมัครหรือในระบบ สามารถกด **"+ เพิ่มรถ"** ได้หลายคัน รองรับทั้งรถยนต์และรถมอเตอร์ไซค์
- **จัดการข้อมูลรถ (`vehicles.php`):** เพิ่ม / ลบ / แก้ไข ข้อมูลรถ (ยี่ห้อ, รุ่น, เลขทะเบียน, สี, ปี, หมายเหตุ) พร้อมปุ่มลัดสั่งซื้อแบตเตอรี่ที่ตรงรุ่นสำหรับคันนั้นทันที
- **จัดการสมาชิกสำหรับแอดมิน (`members.php`):** เพิ่ม / ลบ / แก้ไข ข้อมูลสมาชิก, กำหนดระดับสิทธิ์ (Admin, Staff, Customer), ดูข้อมูลรถทั้งหมดของสมาชิก

### 2. ระบบประกันและเคลมสินค้า (Warranty & Claims)
- **ข้อมูลประกันสินค้า (`warranty.php`):** บันทึกหมายเลขซีเรียล (Serial Number), ชื่อสินค้า, ยี่ห้อ, วันที่ซื้อ, ระยะเวลารับประกัน (เดือน), วันหมดประกัน, ข้อมูลรถและทะเบียน
- **ตรวจสอบระยะประกันสินค้า:** มีแถบ Progress Bar นับถอยหลังจำนวนวันที่เหลืออยู่ในประกัน พร้อมแถบค้นหาด้วยหมายเลขซีเรียล ทะเบียนรถ หรือชื่อสินค้า
- **แจ้งเคลมสินค้า (`claims.php`):**
  - เลือกว่าจะส่งเคลมแบบ **"เปลี่ยนใหม่"** หรือ **"ส่งบริษัท"**
  - กรอกรายละเอียดปัญหาที่พบ (เช่น เก็บประจุไม่อยู่, สตาร์ทไม่ติด, บวม)
  - แนบ **รูปถ่ายสินค้าที่มีปัญหา** (รองรับการถ่ายรูปผ่านกล้องมือถือและอัปโหลดหลายรูปพร้อมดูพรีวิวสด)
  - แอดมินสามารถอัปเดตสถานะการเคลม (รอดำเนินการ -> กำลังตรวจสอบ -> อนุมัติ/ปฏิเสธ -> เสร็จสิ้น) พร้อมบันทึกข้อความสรุปผล

### 3. ระบบสต๊อกสินค้า (Inventory & Stock)
- **บันทึกรับเข้าสินค้า (Stock In) ใน `stock.php`:** บันทึกวันที่รับสินค้า, ผู้จัดจำหน่าย (Supplier), จำนวน, ราคาต้นทุนต่อหน่วย พร้อมตัวเลือกลงบัญชีรายจ่ายอัตโนมัติ
- **บันทึกการขายสินค้า (Stock Out) ใน `stock.php`:** บันทึกวันที่ขายสินค้า, ลูกค้า/ทะเบียนรถ, จำนวน, ราคาขาย พร้อมตัวเลือกลงบัญชีรายรับอัตโนมัติ
- **ค้นหาข้อมูลสินค้า:** ค้นหาตามชื่อสินค้า, รหัส SKU, ยี่ห้อแบตเตอรี่, สถานะสต๊อก
- **การแจ้งเตือนสินค้าใกล้หมดอัตโนมัติ:** เมื่อสินค้าคงเหลือน้อยกว่าเกณฑ์ขั้นต่ำ (`quantity <= min_quantity`) ระบบจะขึ้นกล่องเตือนสีแดง, แสดงตัวเลขเตือนที่เมนูด้านซ้าย, แจ้งเตือนในกระดิ่ง Notification และมีปุ่ม **"รับเข้าสต๊อกด่วน"** ทันที

### 4. ระบบบัญชี (Accounting & Receipts)
- **ตรวจสอบรายรับ-รายจ่าย (`accounting.php`):** แสดงการ์ดสรุปยอดรายรับรวม, รายจ่ายรวม, และกำไรสุทธิ (Net Profit)
- **ตัวกรองช่วงเวลา:** วันนี้, สัปดาห์นี้, เดือนนี้, ปีนี้, ทั้งหมด หรือกำหนดช่วงวันที่เอง
- **เพิ่ม/ลบ/แก้ไข รายรับ-รายจ่าย:** หมวดหมู่, จำนวนเงิน, วันที่ทำรายการ, หมายเหตุ
- **พิมพ์รายงาน / ใบเสร็จรับเงิน (`receipts.php` & `print_receipt.php`):**
  - ออกใบเสร็จรับเงินหน้าร้าน หรือสร้างจากคำสั่งซื้อออนไลน์
  - ระบบแปลงตัวเลขเป็น **ตัวหนังสือภาษาไทยอัตโนมัติ (BahtText)** เช่น "สองพันสองร้อยบาทถ้วน"
  - มีหัวบิลร้านพรชัยแบตเตอรี่ บางพลี, ที่อยู่, เบอร์โทร, เลขประจำตัวผู้เสียภาษี, ตารางรายการสินค้า, ส่วนลด, ภาษีมูลค่าเพิ่ม (VAT), เงื่อนไขการรับประกัน และช่องลงลายมือชื่อ
  - ปรับแต่ง CSS `@media print` สำหรับสั่งพิมพ์ลงกระดาษ A4 หรือเครื่องพิมพ์สลิปได้อย่างสวยงาม

### 5. ระบบสั่งซื้อสินค้า (Ordering & Recommendation)
- **สั่งซื้อแบตเตอรี่ (`orders.php`):** รองรับทั้งแบตเตอรี่รถยนต์และรถมอเตอร์ไซค์
- **ระบุตำแหน่งจัดส่ง:** มีช่องกรอกที่อยู่จัดส่ง และปุ่ม **"ระบุตำแหน่ง GPS"** โดยใช้ HTML5 Geolocation API ดึงพิกัดละติจูด/ลองจิจูด และมีปุ่มเปิด Google Maps สำหรับช่างนำทางไปส่งแบตเตอรี่
- **รูปถ่ายแบตเตอรี่เดิม:** ลูกค้าสามารถถ่ายรูปแบตเตอรี่เดิมในรถผ่านกล้อง เพื่อให้ช่างตรวจสอบขั้วจม/ขั้วลอย (L/R) และขนาดแอมป์ก่อนออกไปติดตั้ง
- **ระบบแนะนำแบตเตอรี่เฉพาะรุ่นรถของลูกค้า:** เมื่อเลือกรถที่ลงทะเบียนไว้ ระบบจะดึงแบตเตอรี่ที่ตรงรุ่นและติดป้าย **"แนะนำ"** ขึ้นมาให้เลือกเป็นอันดับแรกทันที
- **จัดการสินค้าแนะนำ (`recommendations.php`):** แอดมินสามารถ เพิ่ม / ลบ / แก้ไข การจับคู่ระหว่าง ยี่ห้อรถ + รุ่นรถ กับ สินค้าแบตเตอรี่ พร้อมตั้งลำดับความสำคัญ (Priority) ได้อย่างอิสระ
